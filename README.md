# QuillMD

WYSIWYG markdown editor with **native markdown persistence** — the `.md` file on disk is the only source of truth. Cross-platform: **Windows + Linux**.

## Status

- **Spec:** v0.1 draft — see [spec.md](spec.md)
- **Council:** five-lens software review (Systems Architect · UX/Product Designer · Engineering Lead · Contrarian · Cross-Platform/QA) — see [COUNCIL.md](COUNCIL.md)
- **Development:** issue → branch → opencode → PR → council audit → Bruce veto → squash merge

## Core principles

1. The markdown file is the source of truth. No proprietary formats, ever.
2. Round-trip fidelity: open → save = byte-identical (for clean fixtures).
3. Full markdown feature set, not a subset.
4. Works identically on Windows and Linux.
